# 《荒原猎手》核心游戏设计

## 玩家幻想
成为一名真正自由的荒原猎人：从贫穷聚落、无战车状态起步，通过探索、赏金、救人、拾荒、战斗与机械改装逐渐拥有自己的战车和名声。

## 核心循环
城镇获取信息/任务 → 整备人物与战车 → 荒原探索 → 随机事件/遗迹/战斗 → 赏金首或任务高潮 → 战利品/关系/城镇状态变化 → 返回整备并开启新路线。

## 世界规模
- 大型世界地图，包含道路、河流、山脉、桥梁、聚落、遗迹、洞穴、矿井、军事基地、竞技场、港口等。
- 10 个风格与社会结构明显不同的主要城镇。
- 10 个大型赏金 Boss，各自拥有独立外观、行为和阶段机制。
- 11 辆可驾驶车辆/战车。

## 战车系统
车辆应支持模块化：
- 主炮 Main Gun
- 副炮 Sub Gun
- SE
- 装甲/Armor
- Engine
- C-unit

改装必须尽可能产生可见外观变化，而非只修改数字。车体与炮塔应分层；炮塔可旋转；履带/轮胎有运动表现；射击有后坐、炮口焰、弹道、命中和爆炸反馈；受损后有烟火/破损状态。

## 人物
核心角色：
- **柳焰**：红发资深猎人，务实，曾属于旧猎人小队。关系通过同行、记忆和安静的个人场景发展。
- **桃夭**：活泼、有天赋的机械师；不敬权威，认为机器坏了至少会诚实地告诉你哪里坏。与机械圣约剧情有重要交集，但不是信徒。
- **林澄**：医护人员，温和但认真，坚持记住患者姓名而不是床号；适合承载医疗、共生体和神经技术伦理剧情。
- **玩家**：普通拾荒者/劳动者背景，无特殊救世主血统；开始没有坦克。

角色游戏 Sprite 目标：8方向，并拥有可读的待机、行走及关键动作动画。最终动作集可包括跑步、射击、近战、受击、倒地、调查、上下车等。

## NPC 与“灵魂”
NPC 不只是功能菜单。重要 NPC 应拥有姓名、生活规律、事件前后对话变化和对玩家行为的记忆。

城镇应在重大事件后产生可见恢复/恶化变化。小人物故事优先于抽象政治宣讲。

## 关系系统
同伴关系通过共同经历、夜间场景、旅途电台闲聊、个人记忆和任务决定发展，而不是单纯“送礼加好感”。

## 战斗
人物战斗与战车战斗都需要强烈反馈。赏金首应有独立阶段、行为和破损状态。战斗场景需要远中近景、环境粒子、炮火、命中、镜头反馈等，而不是静态图 + 血条。

## 进度与声望
主要长期指标：
- Hunter Rank
- Town Reputation
- Companion Relationships
- Equipment / Vehicle Progression
- World State

禁止用三大阵营声望迫使玩家政治站队。

## 内容哲学
“更多系统”不等于“更完整”。优先确保已有城镇、NPC、Boss 和车辆有辨识度、反馈和后果，再扩张数量。
