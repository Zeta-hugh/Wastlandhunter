# 《荒原猎手》美术与视觉方向

## 当前问题判断
0.23 Canon Build 的故事骨架和世界观明显进步，但实际游戏视觉仍非常粗糙。玩家第一眼的印象显著拉低整体完成感。

当前视觉成熟度只能按约 20–30% 看待；综合玩家感知约 30–35%。不得因为剧情/代码功能数量而宣称达到 80%。

## 当前最高优先级
暂停无节制横向扩张，先进行一次 **Visual Vertical Slice**。

第一目标：
**锈港 + 玩家角色 + 柳焰 + 第一辆战车 + 铁牙猎犬**

这部分必须做到可以作为真实游戏宣传截图展示的程度，再复制生产规范到其余城镇。

## 总体视觉语言
- 后核废土，但不是只有灰褐色。
- 3/4 俯视 RPG 视角为主。
- 像素/像素化表现可以保留，但必须具有明确材质、体积、光影、层次与可读性。
- 旧世界工业残骸 + 手工维修 + 局部高科技形成反差。
- 不允许大量纯色矩形、CSS block、emoji 或通用占位符长期充当正式资产。

## 世界地图
需要真正 tileset：荒漠、盐碱地、草地、森林、岩山、河流、海岸、公路、铁路、桥、弹坑、废墟、旧高速等，并具有自然过渡和地标辨识度。

## 城镇
建筑需要屋顶、墙面、门窗、招牌、遮阳棚、管道、电缆、垃圾、灯箱、空调、楼梯、前后景遮挡等细节。不同城镇拥有不同材料和轮廓语言。

## 人物
主角和主要同伴的小人必须能与角色设定对应，不能出现“立绘是一个人，Sprite 像另一个人”的感觉。

对话中的人物表现优先使用透明背景、场景融合的半身 cutout/sprite，而非一个矩形海报头像贴在对话框旁。

## 战车
战车不能只是小图标。至少拆分 chassis / turret / weapons 等视觉层，并表现履带/轮胎、炮塔旋转、后坐、炮口焰、受损烟雾等。不同车辆必须有明显轮廓差异，而不是换色。

## 怪物与 Boss
普通敌人应形成生态：战争机器、工业机械、变异兽、车匪、AI幽灵载体等。

10 个赏金首必须拥有真正独立的大型 Sprite/模型语言、攻击动作、阶段变化、破损和死亡反馈。禁止仅通过换色和改轮廓伪装成不同 Boss。

## UI
对话、菜单、装备、车库、赏金榜、地图、人物档案应使用统一的废土机械视觉系统：一致的边框、字阶、图标、按钮状态和交互反馈。

## 环境表现
逐步加入昼夜、室内灯、霓虹、火焰、烟、雨、沙尘、水面、车灯等，让世界具有正在运行的感觉。

## 视觉里程碑验收
未来报告视觉里程碑时，必须优先提供 **实际运行截图**，而不是概念图。

固定检查至少六种真实游戏画面：
1. 大世界
2. 锈港街区
3. 酒馆/室内
4. 玩家与 NPC
5. 战车车库
6. 铁牙猎犬赏金战

如果真实截图仍明显像网页原型，而参考效果像正式游戏，则视觉里程碑尚未通过。
