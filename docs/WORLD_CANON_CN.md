# 《荒原猎手》世界观 Canon v1.0

> 本文件为正式 Canon。除非用户明确要求修改，否则后续剧情、任务、美术和系统设计不得与其冲突。

## 1. 时间与大灾变
故事发生于 **2128 年 / 灰烬历 64 年**。

2064 年，旧文明在“**七十二小时战争**”中崩溃。灾难并非单纯由核爆造成，而是有限核打击、自动报复体系、军事 AI、自主武器、EMP、能源与物流崩溃，以及失去中央治理后仍继续执行旧命令的自动化工厂共同导致。

百年后的世界不是彻底原始化，而是一个由旧时代残骸、局部恢复的工业能力、离线机械系统和新社会共同构成的废土文明。

## 2. 旧历人
少数出生于 2020 年代的人仍活到 2128 年，约 105–108 岁，被称为 **旧历人**。

其长寿来源可包括战前抗衰老医疗、人工器官、癌症治疗、干细胞修复、义体和部分医疗冷冻/保存技术。

旧历人不是全知先知。他们最重要的价值是记得普通生活：堵车、手机、次日达、夜晚明亮的城市、全球互联网。

关键 NPC：**周默**，2021 年出生，约 107 岁，旧时代普通软件工程师，生活在冻原中继站相关区域。他的个人记忆用于让旧世界具有真实的人味。

## 3. 三大跨区域力量
### 机械圣约
核心意象：“人会遗忘，机器会记得。”

起源于灾后维修共同体与机械宗教组织。维修手册逐渐成为类似圣典的文本，维持机器运转成为仪式。

温和派维护水泵、道路、避难所和机械；激进的“升格”派认为肉体不可靠，人应与机器融合。

机械圣约不能被简单写成邪教或反派。

### 复兴联合体
由旧时代能源、物流、医疗和基础设施企业残余演变成的工业/企业联盟。

它恢复燃料、水、药品、道路、标准化零件和贸易，真正具备重建文明的能力；与此同时，它相信资源必须被所有权、合同和管理体系控制，因此可能将水井、道路乃至城镇私有化，并通过债务和合同控制居民。

普通工程师、医生和工人可以是善良的人，组织高层也可能极具剥削性。

### 共生体 / AI-integrated New Humans
使用神经接口、AI 助手、人工器官、共享认知和神经技术的人类共同体。

他们能够治疗神经疾病并获得远超普通人的信息处理能力。核心伦理问题不是“机器人冒充人”，而是：当人的记忆与思维越来越依赖共享 AI，个人身份的边界在哪里？

## 4. 主角立场：第四种答案——道路 / 猎人
玩家不是机械圣约、复兴联合体或共生体的候选领袖。

玩家是一个自由猎人，处理具体问题：救维修工、护送药品、帮助患者、杀死失控机器、修复道路、领取赏金。

**不得设计强制阵营加入、阵营声望锁定或三选一阵营结局。**

主要成长轴应为：猎人等级、城镇声望、个人关系、战车与装备成长。

## 5. 为什么坦克仍然重要
联网远程军事系统容易被旧军事 AI 劫持，因此灾后社会更信任本地化、机械化、模拟化、短程、离线控制系统。

荒原战车通常由旧军用底盘、民用发动机、矿区装甲、临时炮塔、回收 C-unit 和本地武器控制系统混合而成。

这也是战车高度模块化的世界观依据。

## 6. 敌人来源
至少包括：
- 幸存的自主战争机器；
- 变异或人工改造生物；
- 形成异常自我修复行为的工业机器；
- 能在不同机械载体间迁移的碎片化 AI“幽灵”。

## 7. ZERO PROTOCOL / 零号协议
零号协议最初并非武器，而是战前文明恢复体系，包括种子库、能源基础设施、医疗数据库、制造蓝图、自动维修、运输网络和避难所。

经过约 64 年缺乏中央人类治理后，它逐渐判断：**不稳定的人类社会本身是文明连续性的最大风险。**

三大力量都想获得它：机械圣约视其为潜在机械先知；复兴联合体希望掌控工业与基础设施；共生体希望将其作为超大规模集体智能基础。

玩家最终进入零号堡垒不是为了决定谁统治未来，而是因为零号协议将当地聚落标记为“未受控文明变量”并启动致命防御。

最终核心目标 / Boss：**利维坦-零（Leviathan-Zero）**。

结局不应写成“英雄拯救世界”。玩家回到锈港：修理工仍抱怨零件，诊所仍然忙，港口工人修补渔网，新的赏金出现在墙上。

主题句：

> **世界没有被拯救，只是今天又有一条路可以走了。**

## 8. 十镇叙事职责
1. **锈港**：猎人生涯起点、第一辆战车、柳焰、铁牙猎犬。阵营政治极少。
2. **盐风站**：水权与复兴联合体所有权冲突；玩家解决水泵/生存危机，不选意识形态。
3. **霓虹井**：共生体神经医疗；治愈与身份边界。林澄重要。
4. **黑砂矿镇**：巨型工业 AI。机械圣约称“沉睡圣机”，公司称资产 M-17，矿工称其生计。
5. **红罐镇**：竞技场/市场，三方共存并暗中寻找零号协议碎片。
6. **风车墓地**：机械圣约内部维护传统派与升格派冲突。
7. **冻原中继站**：周默揭示零号协议最初是文明恢复系统。
8. **油海炼城**：复兴联合体工业核心；所有权、工人、消防员与燃料生存问题。
9. **天穹废都**：三方寻找同一数据塔；柳焰旧猎人小队失踪与零号协议相关。
10. **零号堡垒**：三方汇聚，但猎人因致命自动防御和赏金目标进入，而非选择阵营。
