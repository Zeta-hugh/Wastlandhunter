# 《荒原猎手》下一阶段路线图

## Phase 1 — 工程迁移与保护
- 将 0.23 保存为 `legacy/`，不覆盖。
- 拆分单 HTML 中可复用的故事数据、任务数据、系统逻辑和存档结构。
- 建立模块化目录和开发入口。
- 建立基本运行/构建检查。

## Phase 2 — 锈港视觉垂直切片（当前最高优先级）
目标不是“把所有系统都做一点”，而是让游戏最早 20–40 分钟达到可信的正式游戏观感。

### 全程 2.5D 视觉硬约束

新运行时从锈港开始采用统一的 3/4 俯视正交 2.5D管线，后续所有城镇、野外、室内、角色、战车、敌人和建筑都必须遵守同一套世界坐标、脚点、深度排序、Z 高度、阴影和遮挡规则。禁止把一个场景做成 2.5D、其他场景退回平面色块或独立的 2D 坐标体系。

- 地面与道路作为可投影的世界平面；
- 角色、战车、敌人以脚点锚定，并按世界 Y 排序；
- 建筑、炮塔、棚屋和特效保留 Z 高度与前后遮挡；
- UI 保持屏幕空间，不参与世界投影；
- 所有正式素材必须通过 manifest/AssetRegistry，`NEEDS_ART` 不能进入发布渲染。

### 锈港
- 重做地面 tiles、道路、港区、棚屋、工坊、诊所/酒馆等关键建筑。
- 增加前后景遮挡、垃圾/管道/电线/招牌/灯光/烟雾等。
- NPC 有职业辨识度与基本生活轨迹。

### 玩家与柳焰
- 建立统一角色 Sprite 规格。
- 8方向基础移动。
- 待机/行走先达到正式质量，再扩充射击、受击等动作。
- 对话 cutout 与场景融合。

### 第一辆战车
- 正式 chassis + turret 分层。
- 方向/转向、履带或轮胎运动、炮塔旋转。
- 主炮射击、后坐、炮口焰、弹道、命中与损伤表现。
- 初步可见模块替换。

### 铁牙猎犬
- 独立大型赏金首资产。
- 至少多个可读战斗状态/阶段。
- 破损、受击、攻击、死亡反馈。
- 战场环境和镜头反馈达到垂直切片质量。

## Phase 3 — UI 与反馈统一
统一 HUD、对话、任务、赏金榜、车库、装备、地图和档案视觉语言。减少“网页控件感”。

## Phase 4 — 将标准复制到前三镇
锈港标准通过后，再升级盐风站和霓虹井，同时实装：
- 盐风站水权/联合体任务链；
- 霓虹井共生体医疗伦理任务链；
- 林澄相关个人内容。

## Phase 5 — 中后期内容生产
黑砂矿镇 → 红罐镇 → 风车墓地 → 冻原中继站（周默）→ 油海炼城 → 天穹废都 → 零号堡垒。

## Phase 6 — Android 与发布工程
- Android 包装/工程稳定化。
- GitHub Actions 自动构建 APK。
- 存档与输入适配。
- 性能、分辨率和移动端 UI 测试。

## 80% milestone 的定义
只有当核心流程大部分可玩，并且真实运行画面已经接近统一正式美术质量时，才称为约 80%。

到该节点应提交：
- 可运行完整构建；
- Android APK/构建产物；
- 源代码；
- 至少六张真实运行截图；
- 已知问题列表；
- 余下 20% 发布清单。
